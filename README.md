## Run

```bash

npm run dev
```

## Build

```bash
npm run build
```

## GitHub Pages

The Vite config uses `base: "./"` so the production build can be hosted as a static GitHub Pages site.

Before launch, replace any portfolio/project text you want to customize and add your actual domain if you later purchase one.
